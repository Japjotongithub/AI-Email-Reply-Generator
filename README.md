# AI-Email-Reply-Generator
1. My Mini project is an AI Powered email response generator that automatically creates professional replies using the Gemini API.
2. Gemini understands the context of the email,after which it generates an appropriate reply
3. I used latest Gemini flash model
4. It takes care of prompt,tone and email.
5. We can vary the tone.I have set the tone as 'formal'
6. The AI analyzes context and communication intent.
